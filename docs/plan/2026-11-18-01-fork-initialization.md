# Fork 初始化计划

## 目标

建立 Centaur 的独立开发仓库，以 `v2026.11.13` 为基线，在 `codex/shared-sandbox` 分支完成共享沙箱升级的准备。首批提交包含项目治理、验收契约和测试计划。

## 实施顺序

1. 确认目标目录和上级指令，建立本计划。
2. 初始化 Git，配置公开 fork 和上游远程，取回指定标签并校验提交 `5041d830dbde1bb66b0a677db6f086defd1eeadd`，从该提交创建开发分支。
3. 阅读上游 README、AGENTS、许可证、源码和 CI，整理事实、开发入口与升级方案。
4. 建立文档索引和初始化变更记录，检查 Markdown、链接、公开内容与 Git ancestry，验证通过后本地提交。
5. 归档已执行的 WSL 基线及剩余验证范围。补充候选镜像的准备方式，并明确按照实例已批准的数据保留策略选择回退路径。

## 验收

- 上游提交是 fork 提交的父提交，许可证与上游一致。
- 项目文档说明首版行为、设计待定项、迁移回退和测试验收门槛。
- 本阶段范围为文档和开发准备。WSL 基线软件测试由主代理独立执行并记录。
